# Quality Checklist

## Brand
- [ ] Sounds like the sample captions in voice.md
- [ ] No banned words, claims or names (words.md)
- [ ] Brand words spelled right
- [ ] Only brand colors and fonts
- [ ] Logo used correctly

## Facts
- [ ] Every fact, number or quote has a source
- [ ] Quotes match the source word for word, right person named
- [ ] No health, money or legal promises

## Rights
- [ ] Every stock clip and photo is in credits
- [ ] Music is only from brand/assets/music
- [ ] Nothing taken from other creators, TV, movies or YouTube

## Platform
- [ ] Right media size for the format
- [ ] Video length inside the settings range
- [ ] Caption, title, description under limits
- [ ] Right number of hashtags
- [ ] Alt text on every image

## Files
- [ ] Every file opens
- [ ] No black or frozen video sections, sound is there
- [ ] Every link opens

## Repeats
- [ ] Not too close to anything posted in the last 30 days
